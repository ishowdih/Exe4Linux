# Exe2Linux
What does this program do?

- It takes the .exe file, copies its inside to itself
- Then runs that with wine.

## Why did i make this
I was bored asf, but wanted to code anyways. Now, because i made this script, i dont have to type `wine file.exe` again and again. I can just double click the file and it runs. Isn't that crazy?
